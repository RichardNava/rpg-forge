# ADR-034 — Catálogo externo deliberadamente pequeño

**Estado:** Aceptada  
**Fecha:** 12/08/2026

## Decisión

Aprobar inicialmente:

```text
cloudflare
vercel-react-best-practices
web-design-guidelines
```

Diferir:

```text
durable-objects
turnstile-spin
vercel-composition-patterns
```

## Motivo

Preferir skills de fabricantes/autores directamente relacionados con el stack y evitar una colección grande de skills solapados.
