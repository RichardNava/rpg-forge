# ADR-027 — Sharing de OpenCode deshabilitado

**Estado:** Aceptada  
**Fecha:** 12/08/2026

## Decisión

Configurar:

```json
"share": "disabled"
```

## Motivo

El repositorio y el desarrollo inicial son privados.

Compartir conversaciones de OpenCode deberá ser una decisión explícita futura y no un comportamiento disponible por defecto en este proyecto.
