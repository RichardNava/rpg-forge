# ADR-037 — Context7 como único MCP inicial

**Estado:** Aceptada  
**Fecha:** 12/08/2026

## Decisión

Activar únicamente:

```text
Context7 remote MCP
https://mcp.context7.com/mcp
```

desde el inicio.

## Motivo

Aporta una capacidad claramente distinta del repositorio local: documentación actualizada y específica de versión.

El resto de necesidades iniciales ya están cubiertas por herramientas nativas, skills y web.
