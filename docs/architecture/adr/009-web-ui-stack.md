# ADR-009 — Next.js 16 + Tailwind 4 + shadcn/Base UI

**Estado:** Aceptada  
**Fecha:** 12/08/2026

## Decisión

- Next.js 16 App Router;
- TypeScript strict;
- Tailwind CSS 4;
- shadcn/ui v4;
- Base UI como base inicial;
- Lucide para iconografía.

## Motivo

Permite construir una UI profundamente personalizada sin una dependencia visual cerrada y mantiene un stack alineado con Next.js moderno.

## Regla

La estética RPG se implementará mediante design tokens y componentes temáticos reutilizables, no mediante estilos arbitrarios dispersos.
