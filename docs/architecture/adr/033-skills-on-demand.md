# ADR-033 — Skills como procedimientos bajo demanda

**Estado:** Aceptada  
**Fecha:** 12/08/2026

## Decisión

Los skills contienen procedimientos especializados y se cargan on-demand.

No duplican las reglas permanentes de `AGENTS.md` ni la documentación de arquitectura.

Skills propios iniciales:

```text
feature-development
rpg-frontend-style
ai-generation
```

## Motivo

Mantener el contexto pequeño y activar conocimiento adicional únicamente cuando aporta valor a la tarea.
