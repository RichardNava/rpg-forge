# ADR-041 — Catálogo mínimo de commands

**Estado:** Aceptada  
**Fecha:** 12/08/2026

## Decisión

Crear únicamente:

```text
/feature
/review
/test
/security
/adr
```

## Motivo

Cubren los workflows repetitivos donde seleccionar el agente/procedimiento correcto aporta valor.

No convertir cada operación trivial o comando shell en un slash command.
